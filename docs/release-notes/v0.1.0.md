First release of System Monitor for Windows: a clean, easy-to-read Task Manager alternative inspired by GNOME System Monitor.

## Download (pick one from Assets below)

| File | How to use it |
|---|---|
| **SystemMonitor-v0.1.0.exe** | Download and double-click. Single file, nothing to install. Takes about 3 s to open. |
| SystemMonitor-v0.1.0-win64.zip | Right-click → Extract All, then run `SystemMonitor.exe` inside the folder. Opens instantly. Keep the exe and the `_internal` folder together. |

No admin rights and no Python needed.

If Windows SmartScreen says "Windows protected your PC", click **More info → Run anyway**. The app isn't code-signed yet.

## Features
- **Processes:** app icons, CPU, memory, disk I/O and priority; search; parent/child tree view; End Process / End Process Tree; Change Priority; Properties
- **Resources:** live graphs for CPU (every core), memory and swap, network, disk, and GPU (usage + memory, every graphics card)
- **File Systems:** every drive with a usage bar
- Light and dark mode (follows Windows)

Requires 64-bit Windows 10 (2004+) or Windows 11.
